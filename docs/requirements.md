# 需求與分階段開發計畫

記錄日期：2026-11-04。來源：使用者對新版 Pentaskill 的需求。新專案與舊 `online-learning-platform` 分離，不修改或搬移舊站資料。

## 已確認需求

- 保留課程商城、會員中心、影片學習與後台課程管理。
- 重新設計個教預約、購課方案、客製報價與付款流程。
- 一對一個教透過外部會議平台（以 Zoom 為設計方向），網站管理堂數與預約，不承載即時影音。
- 新增四階段學習地圖：AI 新手、理論基礎、進階實作、開發者。
- 透過少量遊戲式情境問題推薦起始課程，以闖關、集點增加學習動機。
- 淺色、簡潔直觀的前端；首頁有精選課程輪播。
- AI 助教與薪資結算延後。
- 新版原始碼與開發紀錄保存到 `Peywen514/Pentaskill`。
